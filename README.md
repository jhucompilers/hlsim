# High-level code simulator

This is a simulator intended to execute "high-level" IR programs
generated by implementations of the [Nearly CC](https://github.com/daveho/nearly_cc/)
educational compiler.

You can see some example high-level programs here:

<https://github.com/jhucompilers/fall2025-tests/tree/main/assign04/example_highlevel_code>

This is a work in progress. As of right now (Monday, Oct 26th, 2026)
it is fairly complete, and successfully executes all of the
test programs in the test repository. However, it's very possible
that there are bugs. Please [let me know](mailto:daveho@cs.jhu.edu)
if you run into any issues with the simulator.

## Building

To build the program, run the commands

```
make depend
make -j
```

The executable is `build/hlsim`.
