# High-level code simulator

This is a simulator intended to execute "high-level" IR programs
generated by implementations of the [Nearly CC](https://github.com/daveho/nearly_cc/)
educational compiler.

You can see some of these example programs here:

<https://github.com/jhucompilers/fall2025-tests/tree/main/assign04/example_highlevel_code>

This is a work in progress. Right now it implements only a small
subset of the instructions in the high-level IR.
